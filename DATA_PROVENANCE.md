# Data provenance

`src/case39_local.m` contains IEEE 39-bus data derived from a MATPOWER-style case39 file and adapted for this example. MATPOWER notes that case-data files are not covered by the code's BSD license: https://matpower.org/license/. Confirm redistribution rights before making this repository public.

`src/demo_scenario.json` is a synthetic perturbation; `fixtures/` contains synthetic input/output samples for interface tests. No real CSG network data is included.
